# Next.js Dashboard

A dashboard application built while working through the **official Next.js App Router course**.

## Overview

A learning project that applies the Next.js App Router, Tailwind CSS, and TypeScript to build a functional dashboard with navigation, layouts, and data-fetching patterns.

## Features

- Next.js App Router structure
- Tailwind CSS styling
- TypeScript

## Tech Stack

Next.js, Tailwind CSS, TypeScript.

## Status

Learning / course project.
